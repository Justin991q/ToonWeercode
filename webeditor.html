Op de Toon

KNMI Open Data API-key

Nu:

Optioneel. Zonder eigen key gebruikt de app de openbare key van het KNMI. Die delen alle gebruikers zonder account, en hij zit daardoor vaak vol ("KNMI is even te druk"). Een eigen key mag 1000 verzoeken per uur doen.

Hoe kom ik aan deze key?
  1. Maak een account op het KNMI Developer Portal met het registratieformulier. Gebruik een e-mailadres dat blijft werken. Het KNMI beoordeelt de aanvraag en antwoordt binnen 2 werkdagen.
    Werkt het formulier niet? Mail dan naar opendata@knmi.nl met als onderwerp Developer account registration, en vermeld je naam en waarvoor je het gebruikt (bijvoorbeeld "weerwaarschuwingen op mijn thermostaat").
  2. Log in op het Developer Portal.
  3. Ga naar de API Catalogue en klik bij Open Data API op Request an API key.
  4. De key staat daarna op het scherm. Kopieer hem meteen: het is een lange reeks letters en cijfers, die meestal begint met eyJ.
  5. Plak hem hierboven, klik op Test key en daarna op Opslaan op Toon.

Let op: het moet een key voor de Open Data API zijn. Keys voor EDR, WMS of de Notification Service werken hier niet. Plak alleen de key zelf, zonder Bearer ervoor.

Weerlive API-key

Nu:

Optioneel, en alleen met een gekozen plaats. Weerlive is een tweede bron naast het KNMI: de hoogste code van de twee telt. De app vraagt elke 10 minuten iets op, dat zijn 144 van de 300 verzoeken die Weerlive per dag toestaat. Een test kost er ook één.

Hoe kom ik aan deze key?
  1. Ga naar weerlive.nl/api/toegang ("Genereer je API-key") en vul het formulier in. Heb je al een account, log daar dan in om je key op te vragen.
  2. Kopieer de key die je krijgt.
  3. Plak hem hierboven, klik op Test key en daarna op Opslaan op Toon.

De key is gratis en bedoeld voor privégebruik. Weerlive vraagt om een bronvermelding; de app noemt Weerlive.nl op zijn schermen. De demo-key van Weerlive werkt alleen met één plaatsnaam en is hier niet te gebruiken. Meer uitleg staat op weerlive.nl/delen.php.
